---

### 🧠 QA Mindset (Filosofía de trabajo)
* **Enfoque preventivo:** Priorizo la detección temprana de errores mediante pruebas de requerimientos y diseño, evitando que los fallos lleguen a producción.
* **Reportes eficaces:** Redacción de bug reports detallados, centrados en pasos claros, resultados esperados vs. obtenidos y evidencias técnicas (logs, screenshots, videos y reportes HTML).
* **Automatización inteligente:** Uso de BDD (Behavior Driven Development) con Gherkin y patrones de diseño como Page Object Model (POM) y Screen Object Model (SOM) para garantizar mantenibilidad y escalabilidad.
* **Calidad integral 360°:** Automatización no solo funcional (API/Web/Mobile), sino también de rendimiento, carga y seguridad dinámica (DAST).

---

### ⚡ En qué estoy trabajando actualmente
Actualmente, he desarrollado y consolidado **FinTrack Automation Monorepo**, una suite empresarial de automatización de pruebas para una plataforma bancaria de micro-transferencias:

- **API Automation:** Diseño e implementación de suite de pruebas de contrato e integración con **Karate DSL + Java 17**, alcanzando un **100% de ejecución exitosa (35/35 escenarios en verde)** con gestión de autenticación Supabase JWT y data-driven testing.
- **Web Automation:** Automatización de flujos E2E de interfaz de usuario con **Playwright + Java 17** implementando el patrón **Page Object Model (POM)** y sincronización asíncrona avanzada.
- **Mobile Automation:** Pruebas funcionales en entorno móvil/responsive con **Appium + JUnit 5** bajo arquitectura **Screen Object Model**.
- **Performance & Load Testing:** Desarrollo de scripts de rendimiento en **Grafana k6** para validar latencia, degradación y resiliencia de Edge Functions ($p(95) < 500\text{ms}$).
- **Security Testing (DAST):** Integración de análisis dinámico de vulnerabilidades mediante contenedores de **OWASP ZAP**.
- **DevOps & CI/CD Pipeline:** Orquestación secuencial de pruebas en **GitHub Actions** con ejecución desatendida, gestión segura de secrets y carga de artefactos/reportes.
